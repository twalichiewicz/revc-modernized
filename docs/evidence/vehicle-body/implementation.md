# Shared vehicle material body integration

The source host now admits resident vehicles at native world insertion, with a world-boundary retry. Collision bounds and skin are available before the first hit; waiting for the stock proxy to report damage would miss a wing or open-door contact outside that proxy. Equivalent measured assets share immutable initialization prototypes. The native class controller remains the sole rigid-motion owner.

The existing material/connectivity kernel now takes actual vehicle bounds, wheel anchors and named part geometry. Effective steel/aluminum sheet parameters, existing armored vehicle policy, surviving component volumes, local deformation and connected-part release apply across the complete107-model catalog. Engine, fuel, electrical, tires/brakes and aircraft lifting/control/rotor effects read the same body state. Native suspension lines and boat buoyancy footprints retain their class-controller contracts. Removed wheel material removes wheel support; retained flat tires still support their carriers.

Certified native weapon acceptance and accepted relative collision impulses queue work once. Native damage proof/mission gates remain in the path. The old independent glass/panel/part/mechanical writers yield. Automobile collision feedback keeps wanted, speech and rumble behavior while its separate vehicle HP/part counters are restored; bike rider injury remains native before its separate vehicle injury path yields. Native door animation remains active, and complete material door loss supplies the native missing-door state.

A transaction stages render geometry, private instance collision, debris and reservoir changes before publishing. Native contacts, LOS, vertical and clear-line queries read that private collision. After native and plugin animation, an explicit render boundary updates the same posed geometry. Local RW frames use a full affine inverse; the stock rigid transpose cannot invert scaled wheel frames. Native wheel LOD callbacks retain owned geometry, while the normal alpha-sort path remains active. Helicopter blur discs are visual effects, including collapsed `windscreen_dummy`/`bump_rear_dummy` frames, and never supply physical material. Material classification is retained independently of mutable render opacity.

Actor pool generations, clump retirement, optional extras and selected OK/DAM atomic variants are retained across recreation. Explicit repair stages healthy original geometry and resets the corresponding native counters; bike garage repair queues the same body repair. Shutdown stops new admission and removes big-list vehicles from world residency before their private collision is destroyed. User save/settings files and the previous Metal executable/plugin are protected by the installer.

## Numerical and scope limits

This is a reduced sheet/section model with calibrated component boxes and inferred mounts, rather than a general shell finite-element simulation. Projectile budgets retain native damage-unit calibration; accepted impact work is converted from native units and bounded to100kJ per material patch. The existing reduced beam rotation/displacement/frequency/load caps remain in force. Local aerodynamic pressure, centrifugal/rotational distributed loads, torsion, general large-strain folding, detailed fastener constitutive laws and a closed rigid/elastic energy solve are absent. Native scripted aircraft paths retain their prescribed controller behavior.

Collision uses material-vertex sweeps and2cm endpoint probes; arbitrary edge-edge CCD and general deep initial penetration are not implemented. Native collision vertices retain1/128m quantization. Admission is bounded to4096 source faces; publication to16000 triangles per mesh; material connectivity retains its existing fragment/vertex/neighbor/incident bounds. Temporary rigid debris uses the existing40-object budget and20-second lifetime. Publication defers when required resources are unavailable. Doors use native hinge animation and inferred material supports. Boat hull flooding is not modeled. Custom material holes/injury graphs are retained through clump streaming but are not serialized into native saves; existing native saved visual damage is supported.

The automated scene is activated only by the regular-smoke environment variables. The installed launcher enters ordinary saved-game GTA:VC, with the source host as default and the original Metal build retained through the existing Previous build route.
