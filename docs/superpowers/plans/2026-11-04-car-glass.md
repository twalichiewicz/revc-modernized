# Car Glass Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Side and rear windows shatter independently from bullets and crashes, alongside the native windscreen.

**Architecture:** Pure pane classification plus a native geometry owner; certified bullet contacts feed the owner, native damage/repair/deletion hooks maintain lifecycle. Rendered geometry is also what rain and precision bullets query.

**Tech Stack:** C++17, macVC 1.0.5217, Makefile fixtures and installed assets.

**Spec:** `docs/superpowers/specs/2026-11-04-car-glass-design.md`.

## Global Constraints

Cars only, bounded memory, no shared geometry/material writes, native damage and proof ownership, CarGlass disabled is a pass-through. Existing handling values are unchanged.

## Review Focus

1. Two cars sharing geometry: breaking one window leaves its sibling and opaque door faces intact.
2. Read-only traces, wall-blocked shots and recycled pool slots produce no glass effects.
3. Repair, clump deletion and allocation failure release references and preserve a valid native clump.
4. Native front windscreen crack/shatter remains single-owned; hidden/missing components never reappear.
5. Real car geometry (damaged variants, quarter windows and transparent lamps) is classified conservatively.

## Review and implementation record

- Baseline `make test` passed before changes. New pane rules, native geometry ownership and impact-consumption tests each failed before their implementation.
- Private copies retain triangle ordinals by collapsing broken faces to zero area. A detached atomic holds the original geometry reference; native `Atomic::setGeometry` owns reference counting.
- Reused the existing Fix hook; only three new patch entries are required. The patcher rejected an accidentally duplicated Fix entry; the existing capacity tests reproduced it, and removing that duplicate restored all eight capacity tests and a 149-hook/6-skip scratch patch.
- Fresh read-only review found two Important issues, no Critical issues: decorations/lamp lenses admitted by transparency alone, and native drive-by/mounted vehicle damage passing a zero position. Both received reproducing tests and fixes.
- Material inventory and exact real-asset fixtures now exclude ambulance/police/fire-service decals, badges/signs, cabbie striping and the Infernus lamp geometry. Glass is accepted only above the measured 20 cm beltline floor and with untextured or measured glass materials. High-alpha Stallion/Pony glazing and the FBI Rancher rear glass remain eligible. Custom glazing textures outside this measured set remain native.
- Native drive-by/mounted scopes accept their zero-position damage argument only alongside the currently certified car/glass contact. Other shot scopes still require the exact impact position. Native damage arguments/results are passed through unchanged.
- Geometry is restricted to a single morph target, 8192 vertices/16384 triangles per atomic, 64 affected atomics per car, 128 damaged cars and a 16 MiB copy budget checked before allocation. Unknown/oversized geometry remains native.
- Native visual acceptance remains pending for shard/audio presentation, rain placement and Pay n Spray presentation. The full runtime owner, reference counts and repair/deletion behavior are fixture-tested; this is not a claim of in-game visual acceptance.
- Parts loosening/detachment and deformation remain subsequent #37 work; this glass pass does not close that issue.
